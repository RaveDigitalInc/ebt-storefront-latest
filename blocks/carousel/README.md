## Overview
This block provides a carousel/slider component used to display multiple items with navigation controls.

## Configuration Options
- **autoplay**: Enable/disable auto sliding.
- **interval**: Time (in ms) between slides.
- **items**: Number of visible items.
- **loop**: Restart carousel after the last slide.
- **arrows**: Show/hide navigation arrows.
- **dots**: Show/hide pagination dots.
